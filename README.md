👋 Sobre mí

Construyo aplicaciones web completas: desde la interfaz que usa el cliente hasta la API, la base de datos y las integraciones que la mantienen actualizada.

Antes de programar integraciones administré un ERP desde dentro, así que diseño pensando en cómo opera realmente una empresa, no solo en cómo se ve la pantalla.

* 🔭 Últimamente: microservicios en Go, sincronización de inventario entre ERPs y plataformas web, y automatizaciones con n8n.
* 🧠 Me interesa: concurrencia, integridad de datos y arquitectura limpia.
* 💼 Busco: rol como Desarrollador Full Stack o Desarrollador Web.

🚀 Proyecto destacado

[Sistema de Reservas Full Stack · Barbería](https://github.com/Orlando-Guerra/ReservaDeCitas_Barberia)

Plataforma de reservas en Go con arquitectura hexagonal, autenticación JWT con roles de cliente y administrador, y panel de gestión de servicios, horarios y agenda.

Lo más interesante: garantiza a nivel de base de datos que nunca existan dos reservas solapadas, incluso con peticiones simultáneas, usando un exclusion constraint de PostgreSQL. Un test con 20 goroutines reservando el mismo turno confirma que siempre gana exactamente una.
